# Unity-Slot-Machine

A polished 2D slot machine game created using Unity and C#.

## Game Overview

This project simulates a casino-style slot machine with spinning reels, randomized outcomes, sound effects, payout logic, and interactive UI elements.

The game was designed to provide a smooth and visually appealing slot machine experience while implementing core gameplay systems using Unity and C# scripting.

## Features

* Smooth reel spinning animation
* Sequential reel stopping system
* Randomized outcomes using RNG
* Win/Lose payout logic
* Coin tracking system
* Lever interaction animation
* Spin, win, and lose sound effects
* Casino-themed UI design
* WebGL Build included

## Controls

* Pull the lever / press the spin button to start spinning the reels

## Folder Structure

* `Scripts/` → Game logic and reel control scripts
* `Sounds/` → Audio clips and sound effects
* `UI/` → User interface assets
* `Scenes/` → Unity scene files
* `Sprites/` → Slot symbols and visual assets
* `Build/` → WebGL Build files

## How to Run the WebGL Build

1. Open the `Build` folder
2. Launch the WebGL build in a supported browser
3. Play the game directly in browser

## Development Approach

The project was developed using Unity UI elements and C# scripting.
The reel spinning and vibration effects were implemented through code-driven animation logic and coroutines to simulate realistic slot machine behavior.
